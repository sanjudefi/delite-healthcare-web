# Delite Health Care Plus LLC - Official Website

A fully responsive, SEO-optimized healthcare website for Delite Health Care Plus LLC, a premier healthcare services provider based in Burlington, Massachusetts.

## Features

- **Fully Responsive Design**: Optimized for mobile, tablet, and desktop devices
- **Comprehensive SEO**: Complete meta tags, Open Graph, Twitter Cards, and JSON-LD schema on every page
- **Modern Healthcare Design**: Clean, professional aesthetic with blue primary color and red accents
- **Accessibility**: WCAG compliant with skip links and semantic HTML
- **Fast Loading**: Optimized assets and minimal dependencies
- **Vercel Ready**: Configured for seamless deployment on Vercel

## Pages

1. **Home** (`index.html`) - Landing page with service overview and company introduction
2. **Who We Are** (`who-we-are.html`) - Company story, mission, values, and team
3. **Our Care Solutions** (`our-care-solutions.html`) - Comprehensive service descriptions
4. **Why Delite Health** (`why-delite.html`) - Key differentiators and testimonials
5. **Join Our Team** (`join-our-team.html`) - Career opportunities with application form
6. **Get in Touch** (`get-in-touch.html`) - Contact form, map, and contact information

## Technology Stack

- **HTML5**: Semantic, accessible markup
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Vanilla JS for form handling and interactions
- **No Dependencies**: Pure HTML/CSS/JS - no frameworks required

## Deployment

### Vercel Deployment

1. Install Vercel CLI: `npm i -g vercel`
2. Login: `vercel login`
3. Deploy: `vercel`
4. Production: `vercel --prod`

### Manual Deployment

Upload all files to any static hosting provider maintaining the folder structure.
